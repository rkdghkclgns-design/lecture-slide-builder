# 강의 슬라이드 빌더 · 디벨로켓에듀

마크다운 교안과 이미지를 넣으면 **디벨로켓에듀 디자인 시스템** 규칙에 맞춰 강의용 슬라이드를 만들어 주는, 브라우저에서 바로 쓰는 **단일 HTML 도구**입니다. 자동 패턴 추론으로 14개 슬라이드 패턴에 내용을 배치하고, 실시간 미리보기·직접 편집·PPTX/PDF/HTML 내보내기를 지원합니다.

> 메인 도구: **[`강의 슬라이드 빌더.html`](강의%20슬라이드%20빌더.html)** (또는 `index.html`이 자동으로 열어 줍니다)

---

## 빠른 시작

이 도구는 정적 파일 묶음입니다. HTML 내보내기가 `fetch()`로 CSS/스크립트를 읽기 때문에, **로컬 서버로 띄우는 것을 권장**합니다 (`file://`로 직접 열면 PPTX·PDF·편집·미리보기는 동작하지만 HTML 내보내기는 차단됩니다).

```bash
# 이 폴더에서 로컬 서버 실행 (아무거나 하나)
python -m http.server 8080
#  → http://localhost:8080/  접속

npx serve .
#  → 안내되는 주소로 접속
```

그 다음 화면에서:

1. **입력** — 왼쪽 패널에 마크다운 교안을 붙여넣거나 `.md`를 불러옵니다. **`.md` 여러 개를 한 번에(또는 나눠서 여러 번) 불러오면 선택 순서대로 이어집니다** — 불러온 목록에서 `▲▼`로 순서를 바꾸고 `×`로 뺄 수 있습니다. 연결된 결과는 위 텍스트 영역에 반영되며, 텍스트를 직접 수정하면 **자유 편집 모드**로 전환됩니다(목록이 해제되어, 이후 수동 편집 내용이 보존됨). (`예제 채우기`로 샘플을 바로 넣어볼 수 있습니다.)
2. **이미지 첨부** *(선택)* — 드롭존에 이미지를 끌어다 놓습니다. 파일명이 `img_…` ID와 같으면 자동 매칭, 아니면 순서대로 빈 자리를 채웁니다.
3. **슬라이드 생성** — 규칙에 따라 제목·리스트·이미지 구조를 분석해 패턴을 자동 배치합니다.
4. **다듬기** — `슬라이드` 탭에서 패턴을 교체하고, `편집` 모드로 텍스트·이미지를 직접 수정합니다.
5. **내보내기** — `PPTX`(편집 가능) · `PDF`(인쇄) · `HTML`(단독 실행 파일).

샘플 교안: [`samples/sample-lecture.md`](samples/sample-lecture.md)

## 교수안 + 슬라이드 편성안 모드

**교수안**(상세 교안: 설명·멘트·표)과 **슬라이드 편성안**(슬라이드 단위 설계: 제목·슬라이드 문구·이미지/시각·핵심 메시지·`대응 교수안`)을 **함께 불러오면**, 빌더가 자동 감지해 합성 모드로 전환합니다.

- **구조·순서·화면 문구 = 편성안** — `### 슬라이드 N` 순서대로, `슬라이드 문구`를 화면 텍스트로 사용합니다.
- **상세 내용(표 등) = 교수안** — 각 슬라이드의 `대응 교수안`(도입/전개 N/정리) 섹션을 찾아, 그 안의 표(GROW·SMART·훈련↔코칭·동기·기대이론 등)를 deck-table로 렌더합니다. 같은 섹션에 표가 여러 개면(예: 전개 4 = GROW + SMART) 슬라이드 제목으로 맞는 표를 고릅니다.
- **패턴 자동 선택** — 표지→인트로, 목차→개요(agenda), 교수안 표→데크 테이블, 비교 2·3항목→2·3-카드, 다항목→체크리스트, `[활동]`→지시·단계 중심(split), 정리→클로징.
- 두 파일을 `.md 불러오기 (여러 개)`로 함께 첨부하고 **슬라이드 생성**을 누르면 됩니다. 한 파일에 둘을 합쳐 넣어도 H1 기준으로 자동 분리합니다.

예제: [`samples/교수안-예제.md`](samples/) · [`samples/슬라이드편성안-예제.md`](samples/) (18장 생성)

## 입력 형식 (Teacher 에이전트 마크다운)

파서는 Teacher 에이전트의 교안 형식을 이해하며, 일반 마크다운으로도 부드럽게 동작합니다.

```markdown
# 강의 제목
도입 문장…

## 💡 학습 목표
*   목표 1
*   목표 2

## 1. 첫 단원 (⏱ 60분)
단원 도입 문장…

### 1.1. 소주제
#### Key Concept
*   **용어** 설명
#### 구체적 사례
*   **사례명** 설명
#### 본문 설명
본문 단락…
```

| 마크업 | 해석 |
|---|---|
| `# 제목` + 단락 | 강의 제목 + 인트로 |
| `## 💡 학습 목표` + 리스트 | 학습 목표 (1장으로 통합) |
| `## N. 제목 (⏱ NN분)` | 단원(섹션). 소요시간은 인식만 하고 슬라이드엔 미표기 |
| `### N.N. 제목` | 소주제(서브섹션) |
| `#### Key Concept / 구체적 사례 / 본문 설명` | 블록 종류 |
| `*   **용어** 설명` | `{label, desc}` 항목 |
| `<div class="image-wrapper"><img src="local:img_XXX">` | 이미지 자리 (중첩 캡션 div까지 정확히 소거) |
| `<div class="instructor-callout">…</div>` | 강사 노트 |
| ` ```mermaid … ``` ` | 다이어그램 블록 |

## 자동 패턴 추론 규칙

`infer.js`가 문서 구조를 14개 패턴으로 매핑합니다.

- **인트로** → 제목 + 도입 문장
- **학습 목표** → 체크리스트 1장 (항목 7개여도 한 장에)
- **개요(agenda)** → 학습 목표 다음, 이번 차시 단원 목록을 2열로
- **Key Concept**: 3항목 → `3-카드`, 2항목 → `2-카드`, 4~6항목 → `체크리스트`
- **구체적 사례**: 1개 → `케이스 스터디`, 2개 → `2-카드 비교`, 3개 → `3-카드`, 4+ → `글머리 리스트`
- **본문 단락** → `좌텍스트/우이미지`(이미지 없으면 단일 컬럼)
- **단원 디바이더**: 이미지 있으면 `섹션 디바이더`(좌텍스트/우이미지), 없으면 `파트 디바이더`(중앙)
- **클로징** → 마무리

> 자동 추론은 **시작점**입니다 — `슬라이드` 탭의 패턴 드롭다운과 `편집` 모드로 다듬어 쓰세요.

## 테마 (KDT / MSW 토글)

헤더의 **KDT / MSW** 토글로 두 테마를 전환합니다(선택값은 브라우저에 저장, 현재 덱에 즉시 반영 + 이후 생성·내보내기에 적용). 기본값은 **KDT**.

- **KDT 테마** — 군청색(다크) 배경 + 주황 액센트(`#F2A24E`) · 라이트 텍스트, Pretendard. 아래 "디자인 시스템 규칙"이 KDT 기준입니다.
- **MSW 테마** — 메이플스토리 월드 코딩 교실 스킨: 크림 그라데이션 배경, 버섯 오렌지 `#f5a623` + 파스텔 포인트(pink·sky·lime) 순환, **Jua**(제목·숫자)/**Gothic A1**(본문), 알약형 아이브로, 더 통통한 라운드 카드, WORLDS 로고.
- 구현은 `html[data-theme="msw"]` CSS 스킨 + 테마별 로고(`assets/msw-logo.png` / `assets/logo-worlds.png`) + 테마별 PPTX 색. 현재 14패턴 구조 위에 스킨을 입히는 방식이며, MSW 전용 레이아웃(표지/STEP/버섯카드 등)은 후속 확장 대상입니다.

## 디자인 시스템 규칙 (KDT 테마 기준)

`slide-system.css`에 디벨로켓에듀 Deck Design System Manual v1.0이 토큰·규칙으로 전사되어 있습니다. 자세한 원본 규격은 [`docs/디벨로켓에듀 강의 슬라이드 컨벤션 v1.0.pdf`](docs/) 참고.

- **캔버스** 1920×1080, 패딩 100px, 라운드 24px
- **컬러** 모두 16진수 · KDT 군청 다크 테마 — 배경 `#243463`/`#18243F`, 카드 `#2D3E70`, 주황 보더 `#E8954A`, 액센트 주황 `#F2A24E`, 라이트 텍스트 `#F1F4FB`/`#C3CCE4`, 표는 라이트 셀 반전. (MSW는 크림+파스텔)
- **타이포** Pretendard(본문) + JetBrains Mono(라벨/번호), 한국어 단어 중간 줄바꿈 방지(`word-break: keep-all`)
- **표** 어두운 덱 위 밝은 셀로 반전(`#DBE2EC`/`#E9EEF4`, 잉크 `#111827`)
- **카드** 보더 단독, 그림자 없음
- **아이콘** 인라인 SVG, hex stroke(`#C9661C`) — PPTX 호환
- **이미지** 원본 비율 유지(`object-fit: contain`), 프레임이 이미지 비율을 자동 채택
- 드라마틱한 AI 톤 카피 배제, 러닝 푸터에 페이지 번호만 표기
- **브랜드 로고** 모든 슬라이드 우측 상단에 로고 고정 표기 — `assets/msw-logo.png`를 런타임에 data URI로 읽어 `--deck-logo`로 적용(파일 교체만으로 로고 변경). HTML·PPTX 내보내기에도 동일 반영. (로고는 `fetch` 사용 → 로컬 서버/배포 환경 필요, `file://`에선 미표시)
- **외곽 테두리** 모든 슬라이드에 주황색(`#E59440`) 라운드 프레임 라인(안쪽 22px)

## 내보내기

| 형식 | 방식 | 비고 |
|---|---|---|
| **PPTX** | PptxGenJS로 네이티브 도형·텍스트박스·이미지 생성 | PowerPoint에서 바로 편집 가능. 래스터화 없음(CORS·폰트 행 없음). CDN(`pptxgenjs`) 필요 |
| **PDF** | 브라우저 인쇄 → "PDF로 저장" | 슬라이드 1장 = 1페이지. 오프라인 동작 |
| **HTML** | CSS+`deck-stage.js`를 인라인한 단독 실행 파일 | `fetch()` 사용 → **로컬 서버/배포 환경 필요** |

> PPTX 텍스트는 `textContent` 기반으로 추출하므로, 미리보기에서 숨겨진(비활성) 슬라이드의 글자도 빠짐없이 들어갑니다.

## 아키텍처

순수 바닐라 JS, 빌드 단계 없음. `강의 슬라이드 빌더.html`이 모듈을 순서대로 로드합니다.

```
강의 슬라이드 빌더.html   도구 셸(UI 크롬) + 패널/탭/내보내기 메뉴
├─ slide-system.css       디자인 시스템 토큰 + 14패턴 스타일 + 인쇄 규칙
├─ parser.js              Teacher 마크다운 → 구조화 문서 모델
├─ patterns.js            아이콘 세트 + 14개 패턴 렌더러
├─ infer.js               문서 모델 → 슬라이드 스펙(패턴 자동 추론)
├─ compose.js             교수안 + 슬라이드 편성안 → 슬라이드 스펙(편성안 구조 + 교수안 내용)
├─ pptx-export.js         DOM → 네이티브 편집 가능 PPTX (PptxGenJS)
├─ deck-stage.js          <deck-stage> 웹 컴포넌트 (라이브 미리보기·썸네일 레일·키보드 내비·인쇄)
└─ builder.js             오케스트레이션: 입력→파싱→추론→렌더·이미지 매칭·편집·내보내기
```

전역 노출: `window.LectureParser`, `window.DeckPatterns`, `window.DeckInfer`, `window.DeckCompose`, `window.DeckPptx`, `<deck-stage>` 커스텀 엘리먼트.

`<deck-stage>` 공개 API: `.goTo(i)` · `.next()` · `.prev()`, 그리고 `slidechange`(내비 변경) / `deckchange`(레일에서 재정렬·삭제·복제) 커스텀 이벤트.
